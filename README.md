# macroPad
Using this as an introduction to the field of schematics making and pcb designing. 
This project is based on the Adafruit MacroPad RP2040 design by Adafruit Industries.

This version modifies the original design to use a Raspberry Pi Pico instead of the original Adafruit board.

Original design: Adafruit MacroPad RP2040
